# Current-source optional MSRV compile helper contract

This helper is prepared for one bounded native macOS arm64 compile check of repository source `9f84aa6d8163257b4e3f3c2fe4a1c7d7b7c3cce6`. The accepted v3 compatible lock is copied from `.scratch/all-tickets/macos-selected-graph-evidence-03/Cargo.lock`; the required SHA-256 is `2ba4b3a0807e32b613ff2e972b893c3fd2e0923fd91803611963f09e93265425`. The lock and every workspace `Cargo.toml` hash are exported with the evidence.

The only Cargo compile command is:

```text
cargo check --locked --lib --features testing-environ,sys,net
```

The helper installs minimal Rust/Cargo `1.77.2-aarch64-apple-darwin` using the existing `/Users/hoppworks/.cargo/bin/rustup` binary with `--no-self-update`. `RUSTUP_HOME`, `CARGO_HOME`, `HOME`, `CARGO_TARGET_DIR`, source, temporary files, downloaded crates/toolchain, and generated outputs all live under the scoped `AGENT_RUNTIME_DIR`. It invokes the installed `rustc` and `cargo` by absolute path, verifies both versions and the rustc host, and never reads shared Cargo/Rustup configuration or writes shared homes. Cargo receives two jobs, incremental compilation off, and dev debug information off.

Before execution, the coordinator must complete independent source review and coordinate the single heavy-build slot. Create one absent session scope under `~/.local/share/agent-builds/rhai/<unique-session-id>/`, set `TMPDIR` to that absolute scope, and run the helper through `/Users/hoppworks/projects/agent-skills/tools/run_scoped.py` with `--timeout 600`. The runner supplies `AGENT_RUNTIME_DIR` and removes its runtime on every normal, failure, timeout, or interruption outcome. Include the complete outer run and evidence export inside the 600-second ceiling; the helper deadline is 540 seconds from its start, including setup and export. After the runner exits, independently verify the exact runtime path in `export.json` is absent, capture the runner status, retire only the exact empty session scope with `rmdir`, and save those cleanup readbacks beside the evidence. Do not use another session's scope.

The helper samples private runtime storage, its own process-descendant RSS, and descendant count about once per second while commands run, and after each command. It stops at sampled storage `1,572,864 KiB` as a 1.5 GiB preemptive limit; the hard storage and RSS ceilings are each `2,097,152 KiB` (2 GiB), with at most 16 descendants. These are sampled limits, not continuous peak measurements. The source archive is frozen with `git archive`; the private lock must match the specified hash before Cargo starts and after it finishes. No lock resolution, source edits, tests, examples, fixtures, native process/socket calls, or measurements are in scope. A nonzero command, version/host mismatch, lock change, resource stop, or deadline expiry is retained as a failed/incomplete result; do not retry within this allocation.

The helper stages command logs, statuses, sampled observations, lock/manifests, tool versions, and the final status under the private runtime. Its first Git archive command runs from the existing private runtime while the source directory is absent; later compiler commands run from the extracted source directory. The frozen repository has no tracked `.cargo/config` or `.cargo/config.toml`; the helper also supplies a sanitized environment and private `HOME`/`CARGO_HOME`, so shared-home wrapper or flag settings are not used. It exports staged evidence to `.scratch/all-tickets/current-optional-msrv-evidence/` before runtime cleanup, and refuses to overwrite an existing evidence directory. The post-run runtime/scope cleanup receipt is supplied by the coordinator's independent readback, since the helper cannot observe cleanup performed after it exits. A successful compile closes only this current-source optional sys/net compilation prerequisite; it does not establish tests, native feature behavior, other operating systems, core MSRV, or release acceptance.

“No native process/socket calls” means the compile check will not call Rhai's target `sys` process APIs or `net` socket APIs, run their fixtures, or measure their behavior. The helper does run host subprocesses for Git, Rustup, Cargo, and resource sampling through `du`/`ps`; those are required setup and custody operations.

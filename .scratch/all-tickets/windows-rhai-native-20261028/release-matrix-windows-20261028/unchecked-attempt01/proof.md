The exported versions are `rustc 1.77.2 (25ef9e3d8 2024-04-09)` and `cargo 1.77.2 (e52e36006 2024-03-26)`.

`RHAI_COMBINED_WRONG_EXPECTATION=1` made the public Engine/SysPackage/NetPackage test fail with Cargo 101 at the fresh host-file assertion (`filesystem-payload` versus a deliberately incorrect expected value). `RHAI_NET_UNCHECKED_WRONG_CAP_EXPECTATION=1` made `unchecked_mode_keeps_the_host_receive_cap` fail with Cargo 101 at the real TCP receive-cap assertion (actual `ab`, deliberately expected `abc`). A separate widened-cap **positive control** set both `RHAI_NET_UNCHECKED_WIDEN_CAP_CONTROL=1` and the `abc` expectation; the same selector passed, confirming the fixture can deliver all three bytes when the host limit is raised. These controls calibrate only their named assertions.

# Native Windows spawn, clone and wait slice

The public `spawn` script returned shared child handles. A real child wrote its PID before release; an independently opened exact process handle confirmed exit 7. `try_wait()` and `wait(0.0)` returned unit while the child was gated, and two clones returned the cached exit and the independently specified lossy stdout/stderr after release. A deliberately wrong exit expectation failed with Cargo 101 after the exact-handle readback; restored full `sys_process_report` and `sys_process_windows` tests passed 7 + 13.

The tested source has 441 manifest-bound files at baseline commit `797395b836b5ce33b79eb162e5bb8e25a2bcfe98` plus uncommitted implementation and test changes; manifest SHA-256 `e9aeca8101114ead49eb350b50852f903ea4016e390ae723da2c17747fcf2016`, lock `12084a90214418632e80bbaf95983925c2c3886f57f40e2a305b4a1ec353d802`, features `testing-environ,sys,metadata`, native Windows Rust/Cargo 1.93.0. Attempt23 supplies the missing-registration baseline. A Rust 1.77.2 Windows-target compile checked the implementation in standard, `no_index,no_float` and `sync,unchecked` profiles before the final test-only assertions; it is compile-only evidence.

The bounded Driver exited zero in 88.137 seconds. Original export SHA-256 `f07920adb19a962648238b7d2a65a67dae28aa2792a034192168dac44900c8ef` contains 206 ordered frames and 13 hash-verified files. All eight journal lengths and CRC32s verified through `REMOVED`, and the exact inner runtime was removed. The original sdc medium was restored; the exact owned host stage and ISO were retired after hash, all-domain reference and fuser checks. The guest outer scope is retained for evidence-first retirement.

This evidence covers only the named spawn/clone/wait slice. Cancellation with pending I/O or inherited pipes, final-drop policies, concurrent wait/kill, panic/handoff faults, managed Jobs, native MSRV and other feature profiles remain unverified. Combined independent review passed for this narrow slice and WIP integration; see `combined-review.md`.

## Limits

These cases prove actual failed evidence capture and failed runtime removal after confirmed Job closure. They do not prove every backend failure injection, arbitrary interruption, any Rhai public Engine call, a Windows Cargo run, release profiles or MSRV. Source-only fixtures and previous accepted Windows rows retain their own narrower applicability.

## Defects and smallest corrections

1. **The outer hard time limit is absent.** Wrapper line 3 invokes the runner without `--timeout 600`. Harness copy at line 14 and toolchain/version calls at lines 70–72 are unbounded; the 120-second Cargo watchdog does not cover them. Add `--timeout 600` to the configured runner invocation. Keep every child in its inherited group. Do not terminate that group from the inner harness: it includes the supervisor that pins ownership. Harness failures should exit nonzero and let the configured runner terminate/reap its group.

2. **Cleanup can falsely certify an old runtime.** Wrapper line 5 reads the fixed `implementation-run-4.log`, irrespective of where this launch writes output. It neither creates nor closes that log. A later successful wrapper can therefore report the previous absent runtime while overlooking its current runtime. Give this invocation one fresh, explicitly owned evidence path; capture/flush/close its output before reading it, and use only its runtime receipt. Emit `runtime_path` immediately after reading `AGENT_RUNTIME_DIR`, before source copy or lock processing, so setup failures retain identity. Check exactly that absolute path after runner completion, including dangling symlinks (`-e` alone treats them as absent). Preserve runner exit status separately from cleanup status, and fail acceptance if either fails or the receipt is missing/ambiguous. Do not inspect or delete foreign paths. Run4's claimed `5vbjvz_t` absence remains independently unverified by this review.

3. **Provenance describes mutable inputs rather than executed inputs.** Harness line 14 copies the live worktree, then lines 30–32 hash the live repository and HEAD. Changes during or after copy can make those hashes disagree with the code Cargo executes. Record dirty/untracked source inputs, the runner/harness/wrapper identity, private cwd, resolved executable paths, OS and Rust/Cargo versions. The current prints do not enforce either constraint. Hash the restored private test again before final acceptance. Avoid copying accumulated evidence/build output into the runtime; use the existing owned source-copy convention with required untracked sources explicitly included.
